# Security

Version 0.1.x is supported. Do not put secrets or exploit details in public
issues. Use [GitHub private vulnerability reporting](https://github.com/KanadeK/ini-stack-audit/security/advisories/new)
when available. If unavailable, open an issue requesting a private contact
without disclosing details. Input size limits are engineering bounds, not a
sandbox; process hostile input under your operating system's resource limits.
